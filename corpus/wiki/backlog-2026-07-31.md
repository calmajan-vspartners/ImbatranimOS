# Backlog — the 2026-07-31 improvement sweep

Briefs 52-86, written from a live walkthrough of the running OS plus a code
read. **All are ungrilled** — they are researched proposals, not locked
decisions, and each says so in its header. Grill before building.

Split out of [status.md](status.md), which has a 200-line cap.

## Already fixed in-session (not briefs)

Three production bugs found during the sweep were fixed and merged the same day
— see [log.md](../log.md) 2026-07-31:

- **System Monitor's process table was empty in every shipped image.** The
  backend shelled out to procps `ps` syntax; Alpine has busybox. Replaced with a
  `/proc` walk.
- **The Git app was dead in the container and on the ISO** — `git` was installed
  in neither. Installed in both, plus a clear 503 if it is ever missing again.
- **Core's `Tooltip` emitted `<button>` inside `<button>`** across 33 call sites.
- Plus: the repo could not `npm install` with its own declared npm 11, and
  `format:check` was red in two packages.

## Dependency order

1. **86** (shortcut registry) before anything that adds a hotkey — so new
   bindings register rather than stay invisible.
2. **52 → 53** before **85**, so `windowStore` and the desktop layer are not
   rewritten twice.
3. **54** before the app briefs that consume the picker (59-69, 76-78).
4. **79 (Trash) → 83 (Storage) → 80 (Backup)**: Backup excludes the Trash,
   Storage reports it.
5. **49 (durable dotfiles)** gates 81, 82, and the storage move in 71/72 — they
   all belong in the one prefs table; do not add a second config store.
6. **48 (the `system` seam)** gates 81, which should be `system.intents`' first
   real payload.
7. **65** (which PDF app wins) before **66**, and **75** before **50**.
