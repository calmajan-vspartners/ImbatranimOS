# Backlog — the 2026-08-07 research sweep

Written after briefs 47-51 + 80-100 closed the previous backlogs (the seam is
live in all 26 apps, dotfiles/associations/startup/workspaces shipped). Five
parallel read-only exploration lenses over the code and corpus produced ~30
evidenced candidates; this page is the synthesis. **All are ungrilled** —
researched proposals, not locked decisions. Grill against the code before
building.

Brief files exist for 101-113 (authored and code-re-verified the same day);
rows 114-136 get their brief file written at grill time, when each is reached —
the row below is the synthesis to grill from.

Recurring sources worth naming: the corpus's own recorded deferrals (16 done
briefs carry them), the user-filed `desktop-drag-selection` todo, the
promote-on-third-use rules that have already fired (context menu, six-hue
palette), and holes the brief-48 seam either fixed the plumbing for
(`onIntent` has zero consumers) or made cheap (protocol additions are one
file).
